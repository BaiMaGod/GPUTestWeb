# GPU性能测试网站 - 产品需求文档

## 1. 产品概述

一个专业级的GPU性能基准测试网站，通过实时3D测试场景、直观的数据可视化和详尽的性能报告，让用户快速评估GPU性能。面向硬核玩家、硬件爱好者和专业评测人员。

**核心价值**：让数据本身成为主角，所有视觉、交互和动画都服务于"性能"这个核心概念的呈现。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 访客用户 | 首次访问者 | 查看GPU信息、运行基准测试、查看报告 |

### 2.2 功能模块

1. **首页/测试页面**：
   - 顶部导航区（Logo、状态指示、GPU型号）
   - 核心测试区（3D场景、实时FPS、开始测试按钮）
   - 实时性能监控面板（FPS曲线图、GPU信息卡、帧耗时详情）
   - 详细测试报告区（综合评分、测试结果表格、导出/重新测试按钮）

## 3. 核心流程

```
用户进入页面 → 系统检测GPU信息 → 用户点击"开始基准测试"
    → 测试进行中（实时FPS、GPU占用率监控）
    → 测试完成（显示综合评分、详细报告）
    → 用户可导出报告或重新测试
```

## 4. 用户界面设计

### 4.1 设计风格

**视觉风格**：暗色模式 + 赛博科技感

**配色方案**：
- 主背景色：#0B0D15（深邃黑）
- 卡片/面板色：#131823（深空灰）
- 主色调：#3B82F6（科技蓝）
- 辅色调：#8B5CF6（电光紫）
- 高性能：#10B981（翡翠绿）
- 中性能：#F59E0B（琥珀黄）
- 低性能：#EF4444（熔岩红）
- 标题字体：#FFFFFF
- 正文字体：#94A3B8

**字体**：
- 中文：-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Microsoft YaHei", sans-serif
- 数字/英文（性能数据）：JetBrains Mono 或 Roboto Mono（等宽字体）

**布局**：单页面设计，从上到下引导用户完成"了解-测试-分析"流程

### 4.2 页面设计详情

#### 顶部导航区
| 模块 | 设计要素 |
|------|----------|
| Logo | 电路线条构成的芯片图标 + "GPUBench" 文字 |
| 状态指示 | "系统就绪" / "测试中..." + 呼吸灯效果 |
| GPU信息 | 右上角显示GPU型号 + 性能等级色块（绿/黄/红） |

#### 核心测试区（Hero Section）
| 模块 | 设计要素 |
|------|----------|
| 3D场景 | 旋转粒子星系或复杂模型，最直接性能展示 |
| 实时数据 | 大号FPS数字 + GPU占用率进度条/环形图 |
| 开始按钮 | 巨大醒目的 "开始基准测试" 按钮，点击后变 "测试中..." + 加载动画 + 预估剩余时间 |

#### 实时性能监控面板
| 模块 | 设计要素 |
|------|----------|
| FPS实时曲线图 | ECharts折线图，X轴时间，Y轴帧率，动态绘制 |
| GPU信息卡 | 显示GPU型号、显存大小、驱动版本 |
| 帧耗时详情 | 柱状图或数字展示渲染帧耗时、GPU计算耗时等 |

#### 详细测试报告区
| 模块 | 设计要素 |
|------|----------|
| 综合评分 | 大号数字 + 评级徽章（旗舰级/主流级等） |
| 结果表格 | 各项子测试（粒子系统、光照渲染、物理模拟）的得分和帧率 |
| 操作按钮 | "导出报告 (CSV/JSON)" 和 "重新测试" 按钮 |

### 4.3 交互与动画

- **页面加载**：内容从下至上淡入，0.6秒
- **测试开始**：3D场景渲染压力逐步增加，避免瞬间卡顿
- **FPS变化**：数字平滑过渡，低于30fps时变黄/红色 + 轻微抖动
- **曲线图**：新数据点带涟漪效果
- **评分揭晓**：数字从0滚动到最终得分

### 4.4 响应式设计

桌面端优先，移动端适配。触摸设备优化。

## 5. 技术实现建议

- **UI框架**：Tailwind CSS + Headless UI / Radix UI
- **图表库**：ECharts（深色主题适配成熟）
- **交互动画**：Framer Motion (React) 或 GSAP
- **3D渲染**：Three.js / @react-three/fiber
